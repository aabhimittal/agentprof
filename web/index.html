agentprof

flamegraph for agent token spend — local-only, no backend, no account

An agent task is 50–200 model calls, and most of every call is context you already paid for. agentprof attributes the bill and then tells you what to do about it: which tool result was re-sent 80 times, which prefix break cost you a cache, which 8 KB file is sitting in your context six times over.

agentprof report --open          # newest Claude Code session in this repo
agentprof proxy --out run.ndjson  # record any agent on the Messages API
agentprof report run.ndjson       # one self-contained HTML file
